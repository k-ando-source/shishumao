# ししゅまお 🐰

写真やスクショから **輪郭・線だけ** を取り出して、**白背景＋黒線**の刺しゅう下絵をつくる Web アプリです。
iPhone のブラウザ（Safari）で使うことを想定しています。

> 画像の処理はすべて端末の中（JavaScript）で完結します。サーバーへの送信・保存は一切ありません。

## 使いかた

1. 「写真をえらぶ」または「カメラで撮る」で画像を読み込む（PC ではドラッグ＆ドロップ／ペーストも可）
2. **とりこみ方**を選ぶ
   | モード | 向いている画像 | 中身 |
   |---|---|---|
   | なめらか線画 | イラスト・人物・風景写真 | DoG（ぼかし差分）でやわらかい手描き風の線 |
   | くっきり輪郭 | 形をはっきり出したいとき | Canny（勾配＋非極大抑制＋ヒステリシス）で細い輪郭線 |
   | 文字・スクショ | スクショ・ロゴ・文字入り | 適応的2値化でベタ面と文字を拾う |
3. スライダーで調整
   - **線の量**…拾う線の多さ（しきい値）
   - **こまかさ**…ディテールの残し具合（前処理のぼかし量）
   - **線の太さ**…線の膨張（1〜4／画像サイズに応じて自動で基準を調整）
   - **ノイズ消し**…小さな点の除去（連結成分の面積で判定）
   - **白線にする**…白黒反転（黒布に写すとき用）
4. 「下絵を保存」
   - iPhone：共有シートが開くので「画像を保存」で写真アプリへ
   - PC：PNG がダウンロードされます
   - うまくいかないときは、プレビュー画像を**長押し →「"写真"に追加」**でも保存できます

## iPhone のホーム画面に追加する

Safari で開く → 共有ボタン → 「ホーム画面に追加」。
アイコン（ししゅまお）付きで、アプリのように全画面で起動します。オフラインでも動きます。

## ファイル構成

```
index.html              画面
css/style.css           デザイン（ししゅまおカラー）
js/lineart.js           画像処理（グレースケール／ぼかし／DoG／Canny／適応的2値化／ノイズ除去／膨張）
js/app.js               画面まわり（読み込み・プレビュー・保存）
manifest.webmanifest    PWA 設定
sw.js                   オフライン用キャッシュ（ネットワーク優先）
assets/                 アイコン一式・マスコット（元イラストから生成）
  icon-source.png       元画像を正方形に切り出したもの
  icon-512/192/180/152/120.png, apple-touch-icon.png, favicon.png
  mascot.png            背景を透過にしたマスコット（画面内で使用）
tools/make-icons.sh     元画像からアイコン一式を作り直すスクリプト
.claude/server.js       動作確認用の簡易ローカルサーバー
```

## 動かす

`index.html` をブラウザで直接開くだけでも動きます。
ホーム画面追加やオフライン対応（Service Worker）を試すときは HTTP で配信してください。

```bash
node .claude/server.js
```

→ http://localhost:8765

同じ Wi-Fi の iPhone から試すときは、Mac の IP を使って `http://<MacのIP>:8765` を開きます。
（Service Worker は `https` か `localhost` でのみ登録されます。実機で常用するなら GitHub Pages などの https 配信がおすすめです）

## アイコンを差し替える

元画像（イラスト）をこのフォルダに置いて、次を実行すると一式が作り直されます。

```bash
zsh tools/make-icons.sh            # フォルダ内の一番新しい画像を使う
zsh tools/make-icons.sh <画像パス>  # 明示指定
```

画面内のマスコット（`assets/mascot.png`）は背景を透過にした版です。差し替えるときは背景透過の PNG を用意してください。

## 仕様メモ

- 作業解像度は長辺 1600px（それ以上は縮小してから処理）
- 出力は白背景＋黒線の PNG（2値）
- 外部ライブラリなし・ビルド不要
